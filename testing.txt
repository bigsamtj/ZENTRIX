**Phantom – Quick Testing Guide (English)**

Follow these steps in order.

---

### 1. Configure `config.php`

Open `config.php` and fill in:

```php
'domain' => 'https://yourdomain.com',          // replace with your real domain

'telegram' => [
    'enabled'   => true,
    'bot_token' => '123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxx',  // from @BotFather
    'chat_id'   => '123456789',                                  // your chat ID
],

'admin_password' => 'sable_phantom_2026',      // <-- this is the default password
```

**Default admin password is:**  
`sable_phantom_2026`

You can (and should) change it.

---

### 2. Make the logs folder writable

```bash
chmod 755 logs
# or
chmod 775 logs
```

---

### 3. Test the Homepage

1. Open `https://yourdomain.com/`
2. Enter a destination URL (example: `https://google.com`)
3. Optionally set a Custom ID (example: `test01`)
4. Click **Generate Phantom Link**
5. You should see the tracking link + Copy button + Live View link

If this works → Homepage is good.

---

### 4. Test Tracking + Telegram Notification

1. Copy the generated link
2. Open it on another browser / phone / Incognito window
3. You should see a short “Loading...” page, then get redirected

Check your Telegram:
- You should receive a message starting with **👻 Phantom Hit**
- If you allow location access on mobile, you will also receive a second message **📍 Precise Location Received**

If the Telegram message arrives → `track.php` and Telegram are working.

---

### 5. Test Live View

1. Click **Open Live View** from the homepage, or go to:  
   `https://yourdomain.com/liveview.php?id=test01`
2. You should see the hit details (IP, location, time, etc.)

If data appears → Live View is working.

---

### 6. Test Admin Panel

1. Go to `https://yourdomain.com/admin.php`
2. Login with the password: **`sable_phantom_2026`** (or the one you set)
3. You should see a list of all tracking IDs

If you can log in and see the list → Admin is working.

---

### Quick Checklist

| Feature                  | How to Test                        | Expected Result                     |
|--------------------------|------------------------------------|-------------------------------------|
| Homepage                 | Open domain                        | Create link form appears            |
| Generate Link            | Fill URL → Generate                | Link + Copy button appears          |
| Tracking                 | Open the tracking link             | Redirect + log saved                |
| Telegram Notification    | Open the tracking link             | Message arrives in Telegram         |
| Precise Location         | Allow location on phone            | Second Telegram message appears     |
| Live View                | Open liveview.php?id=xxx           | Hit data is visible                 |
| Admin Panel              | Login at admin.php                 | List of tracking IDs appears        |

---

**`sable_phantom_2026`**

Change it in `config.php` after testing.

**Short answers:**

### 1. Does it work without hosting?

**No.**

Phantom is a **PHP web application**. It needs a web server that can run PHP (Apache, Nginx, LiteSpeed, etc.).

You **cannot** just open the files locally with double-click like a normal HTML file. It needs:

- A real domain or subdomain **or**
- Localhost with a local server (XAMPP, Laragon, WAMP, LocalWP, etc.)

**Options without paid hosting:**

| Option              | Works? | Notes                                      |
|---------------------|--------|--------------------------------------------|
| XAMPP / Laragon     | Yes    | Best for local testing on your computer    |
| InfinityFree / Byet | Yes    | Free hosting (has limitations)             |
| 000webhost          | Yes    | Free hosting                               |
| Ngrok + Localhost   | Yes    | Temporary public link from your computer   |
| Just opening files  | No     | Will not work                              |

---

### 2. Default Admin Username

There is **no username**.

The admin panel (`admin.php`) only asks for a **password**.

- **Default password:** `sable_phantom_2026`
- No username field exists.

Just go to:
```
https://yourdomain.com/admin.php
```
and enter the password.

**How to access the Admin Panel**

```
https://yourdomain.com/admin.php
```

(Replace `yourdomain.com` with your real domain)

4. Enter the password:

```
sable_phantom_2026
```

5. Click **Login**.

You will then see the list of all tracking IDs.

---

- If you changed the password in `config.php`, use the new one instead.
